# 独立代理链路、通用工具与网址预设

日期：2026-10-03

需求：代理节点和链路分开管理；在链路内按顺序加入节点或已有链路，可嵌套、批量复制并分别决定是否展示给实例。修复随机窗口尺寸，增加 TOTP、账号清单解析和可保存的网址预设。

实现：
- `src/store.js` 将配置升级为 version 3，增加独立 `settings.chains`，支持嵌套展开、环路/引用/长度校验、节点与链路复制数量 1–200；旧 version 1/2 的前置关系迁移为显式链路并保留实例所选路径。
- `src/api.js` 提供链路增删改、复制、测试与实例选择接口；`public/index.html`、`public/app.js`、`public/style.css` 增加链路编辑与复制弹窗、可见性控制和实例下拉分组。
- `public/totp.js`、`public/tools.js` 加入 Base32 TOTP 与“账号清单解析”；浏览器内解析、动态更新、字段复制，不将密钥保存到服务器。网址预设保存在 GUI 配置中，输入无协议域名时默认 HTTPS。
- desktop 插件新增 `window-size.js`，根据 X 显示尺寸限制可见窗口；同步安装到同级 `camofox-browser/plugins/desktop/`。旧有的关闭窗口阻止重启及被动探活修复继续保留。
- README 和示例图更新；备份正式配置到 `~/.camofox-gui/config.json.pre-v3-20261003`（权限 600），并重启 8790 GUI。

验证：`npm test` 42/42；`git diff --check`；1280×800 Xvfb 下真实 Chromium 管理页和 Camoufox 集成通过，窗口为 1200×720，关闭最后一页后无自动重启；实际复制账号密码到剪贴板通过；正式配置中 4 个实例的代理路径及凭据在迁移前后逐一相同，当前 4 个实例均未运行。工作树尚未提交或推送。
